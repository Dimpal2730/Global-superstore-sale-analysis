Global Superstore Sales Analysis

Data Analytics Project Using Power BI

Project Overview

Global Superstore Sales Analysis is a data analytics project that analyzes sales data using Microsoft Power BI. The project helps understand sales, profit, product categories, customer segments and regional performance.

Project Objectives

  • Analyze overall sales and profit.
  • Compare sales across product categories.
  • Analyze regional sales performance.
  • Understand customer segment performance.
  • Identify monthly sales trends.

Dashboard Features

  • Total Sales KPI Card
  • Total Profit KPI Card
  • Total Quantity KPI Card
  • Sales by Category Chart
  • Sales by Region Chart
  • Sales by Segment Chart
  • Monthly Sales Trend Chart
  • Interactive Slicers and Filters

Tools Used

  • Microsoft Power BI
  • Power Query
  • DAX
  • CSV Dataset
  • HTML and CSS

How to Use

  1. Download the project files from GitHub.
  2. Open the PBIX file in Power BI Desktop.
  3. Load the required CSV dataset if prompted.
  4. Explore the dashboard charts and filters.

Conclusion

This project provides insights into sales, profit, product categories and regional performance. Power BI helps present business data through interactive dashboards and visualizations, supporting better data-driven decisions.
