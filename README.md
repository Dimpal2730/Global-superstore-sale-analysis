
   
# Global Superstore Sales Analysis Dashboard

## Project Overview
This project presents an interactive sales analysis dashboard created using Microsoft Power BI. It analyzes Global Superstore data to understand sales performance, profitability, product categories, and customer segments.

## Project Objectives
- Analyze total sales and total profit.
- Understand sales performance by product category.
- Compare sales across different regions.
- Analyze sales by customer segment.
- Identify monthly sales trends.
- Provide interactive filtering using slicers.

## Tools Used
- Microsoft Power BI
- Global Superstore Dataset
- Data Visualization
- Data Analysis

## Dashboard Features
- **Sales:** Displays overall sales.
- **Profit:** Shows the total profit generated.

- **Sales by Category:** Compares sales across product categories.




## Conclusion
This project demonstrates how Power BI can be used to analyze sales data and present key business insights through interactive visualizations. It helps understand sales performance, profitability, and category-wise trends.
